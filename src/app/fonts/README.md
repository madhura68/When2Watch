# Fonts

Vis type faces, self-hosted so the app makes no request to Google Fonts.

- `PublicSans-latin.woff2` — Public Sans, variable weight 400–600, latin subset. SIL Open Font License 1.1 (U.S. Web Design System).
- `SourceSerif4-latin.woff2` — Source Serif 4, weight 500, optical size 8–60, latin subset. SIL Open Font License 1.1 (Adobe).

Source: Google Fonts static files (publicsans v21, sourceserif4 v15), fetched 2026-10-08.
